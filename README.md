# CRUD con Express

Aplicación **Express** con interfaz web en `public/` para gestionar un listado de personas (nombre, apellido, fecha de nacimiento, foto y descripción). Los datos se guardan en `src/db.json`.

## Endpoints
- `GET /malecon`: listar
- `POST /malecon`: crear
- `PUT /malecon/:id`: actualizar
- `DELETE /malecon/:id`: eliminar

## Cómo ejecutar
```bash
npm install
npm run dev
```

## Proyecto de aprendizaje
Práctica de Express, rutas REST y consumo desde el front-end.
